## In-Memory База данных
### Основной функционал
* CRUD-операции, которые являются методами структуры `UserTable`
* Обработка ошибок ввода(отрицательный возраст, невалидный номер телефона)
* Простой консольный интерфейс
### Структура проекта
```PIOA_M6O_122_.25/
├── src/
│   └── db/
│       ├── backend/
│       │   ├── __init__.py
│       │   ├── errors.py
│       │   └── memory.py
│       └── endpoints/
│           ├── __init__.py
│           ├── __main__.py
│           └── tui.py
└── test/
    ├── __init__.py
    ├── tes_endpoints.py
    └── test_memory.py
```
Функционал самой базы данных - backend, интерфейса - endpoints, тесты - test
### Особенности
Проект был написан по принципу TDD(покрытие тестами - 97%), функционал базы данных реализован через ООП:


`UserTable` - структура, (скрытым)полем которого является вся база данных, а методами - CRUD-операции, редактирующие его


### Запуск
Для запуска необходима версия Python 3.14.3 и выше. `git clone https://github.com/h3xhmmr/PIOA_M6O_122_.25.git`. Запуск самого проекта `python -m src.db.endpoints`. Тесты `pytest --cov=src --cov-report=term-missing`
